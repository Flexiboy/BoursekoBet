# BoursekoBet

Site de "paris" pour les membres de la communauté Bourseko.

Démarrer le serveur Vite+React --> npm run dev
Adresse du site --> http://localhost:5173

Démarrer le serveur Node.JS --> node src/backend/index.js
Adresse de l'API --> http://localhost:3001

Base de données PostgreSQL
Accès à la base de données --> psql postgre
